InfoQ Homepage News AGNTCon + MCPCon 2026: Agentic AI Foundation Adds Four Projects as MCP Turns to Security

Oct 26, 2026 5 min read

At AGNTCon + MCPCon North America 2026 in San Jose, the Agentic AI Foundation (AAIF) added four projects, taking it from three founding projects to ten in its first year. The October 22-23 event followed PyTorch Conference at the same venue, and much of its program moved from new protocol features to security and identity.

Mazin Gilbert, executive director of the AAIF, opened with the project news and three new governance committees. Alibaba contributed OpenSandbox, a secure sandbox for running agents, and OpenAI contributed Open Responses, an open specification for interoperable LLM interfaces. Anthropic added Agent Skills, and Hugging Face added OpenEnv, a framework for reinforcement learning environments that train and evaluate agents. Manik Surtani, the foundation's CTO, put the milestone this way in the announcement:

A year ago, AAIF launched with three projects and a bet that agentic AI needed a neutral home to thrive. Today we host 10.

In "Who Keeps It Open?", Surtani argued that a license alone does not keep infrastructure open. Surtani contrasted Android, which stayed under one company, with Kubernetes, which Google moved into a neutral foundation. The open problems now sit in identity, attestation, audit, and payments.

Outside coverage was cooler. The New Stack noted that Open Responses already has support from AWS Bedrock, Databricks, Ollama, Nvidia, and vLLM, but that Anthropic still defines its own Messages API and Google its Interactions API. The Register headlined its story "Vendor-affiliated AI agent tech gets adopted by friendly, funded foundation" and closed with a caution:

This enthusiastic (or credulous) embrace of AI agents may be a bit too rapid for some industries.

J.R. Storment, executive director of the 11-week-old Tokenomics Foundation, told the audience to stop counting tokens. Cost per task beats cost per token, and cost per outcome is better still, but the real measure is business value.

David Soria Parra, co-creator of MCP at Anthropic, argued that capable models now need connectivity more than help staying on task. The July 28 specification added stateless servers, which some developers worried would turn MCP into just another API, and some platforms already see about 70% of their traffic in that mode. Soria Parra announced MCP tasks support in Claude Code, letting tool calls run for minutes, hours, or days instead of seconds. Anthropic also donated the Agent Skills standard to the foundation. The project's roadmap names five priority areas, from agent messaging and skills over MCP to identity and an HTTP-native transport.

OpenAI's Thomas Sarlandie shared what the ChatGPT plugin directory reveals about MCP servers in production. There is no practical limit on tool count, but oversized schemas get trimmed, starting with argument descriptions. About three in four tool schemas on published servers are under 1 kB, while the largest reach about 260 kB for a single tool and 1.4 MB for a server. OpenAI rejects submitted servers unless every tool carries annotations, which let ChatGPT fast-track read-only calls and confirm destructive ones. Only 56% of plugins use server instructions, which Sarlandie said can safely run to about 1,000 characters.

Chrome's Sarah Drasner presented WebMCP, a proposed web standard now in origin trial that lets websites expose tools to agents. Agents call declared tools instead of scraping the DOM, and Drasner cited benchmarks showing actions 2.5 to 7.5 times faster. Read-only and untrusted-content hints also help agents resist prompt injection hidden in user comments. WebMCP complements MCP rather than replacing it, Drasner stressed.

Dawn Song, a UC Berkeley professor, argued that frontier AI will help attackers more than defenders in the near term. Song's CyberGym benchmark spans more than 1,500 vulnerabilities in nearly 200 open source projects, and models now find zero-days. On ExploitGym, GPT-5.6 Sol produced about 230 working exploits against 869 targets in two hours, and still more than 80 with standard security mitigations enabled. Because attackers need only one hole, Song called for secure-by-construction systems with AI-generated proofs and pointed to a new observatory that tracks these capabilities.

Anthropic's Den Delimarsky, the protocol's lead maintainer, said cumulative SDK downloads have reached 4.17 billion. The count stood at about 3 billion a month earlier, which Delimarsky said raises the stakes of every security gap. About a third of the 116 conformance scenarios now test security, and enterprise-managed authorization is live in Claude. Delimarsky's auth roadmap marks that feature stable, puts proof-of-possession tokens and workload identity federation in draft, and ends with agents that sign in as themselves.

Block's Bradley Axen, creator of goose, demonstrated Buzz, an open source workspace where people and agents share channels. Each agent gets its own identity plus an attestation naming its owner, and can read channels but not direct messages. Buzz has 80,000 communities and 36,000 GitHub stars, with version 1.0 due in mid-November.

Thomas Dohmke, former GitHub CEO and now CEO of Entire, said agents have turned code review into the bottleneck. Citing industry data, Dohmke noted that teams using coding agents produce about 57 pull requests a week, against roughly 10 for others. Dohmke wants agent session logs stored in Git and linked to commits, so reviewers can check a change against its intent.

Tim O'Reilly called MCP an "architecture of participation" for AI, in the tradition of Unix. The AI economy still lacks its mechanisms, O'Reilly argued, much as the web needed pay-per-click advertising and secure payments. O'Reilly framed the fix as mechanism design, or "reverse game theory": start from the outcome you want and work backward to the rules that produce it. His message was to move trust out of the model and into protocols, gateways, and verifiable identity.

For teams running MCP servers, the practical lessons were specific: annotate every tool, keep schemas small, and plan for agents that carry their own identity rather than a borrowed user token. Several figures were stage claims without published data, and some security extensions remain drafts. Developers interested in learning more can watch the Day 1 and Day 2 keynote livestreams or read the foundation's project pages. The next AGNTCon + MCPCon events are set for San Francisco on April 28-29 and London on September 15-16, 2027.

#2485. Why Does My Dog Always Steal My Spot? The Reason Will Warm Your Heart

📅 Oct 26, 2026  |  Category: Lifestyle  |  Read Source →

Experts break down the intentions behind your pup’s habit.

Being a dog owner can be extremely rewarding. In many ways, it’s like being given an adorable, cuddly, playful roommate whose main goal in life is to love you unconditionally. I mean, that’s the dream, right? But like with most things, it can also come with a few notable challenges: the main one being their inability to verbally communicate with you. If I had a nickel for every time I wished I knew what my dog was thinking… well… let’s just say I’d be in a different tax bracket by now. It can be frustrating not to know what is going on in those furry heads of theirs, not just in regard to how they’re feeling physically, but on a behavioral level as well. One example that immediately comes to mind is my own dog’s peculiar habit of stealing my spot on the couch as soon as I leave it.

For a little bit of background, my dog’s name is Luna. She is an 8-year-old yellow lab who loves to snore, wag her tail in a helicopter motion, hoard tennis balls and never give them back, and, yes, steal other people’s seats on the furniture. It doesn’t matter if she’s sitting in a similar spot to us, or even right next to us; she will proceed to take your seat the moment you get up to get a snack or use the bathroom or simply grab a nearby blanket. It’s equal parts frustrating and amusing. What exactly is making her do this? As much as I wish my dog could answer that question for me directly (and believe me, I have wondered if she is secretly a human trapped in a dog’s body due to some sort of Beauty and the Beast-style enchantment, but that probably isn’t the case), the habit has inspired me to seek answers elsewhere.

Since I’m sure my dog isn’t the only canine committing furniture theft, Scary Mommy reached out to a few experts to get their insight on what your pup’s real motive may be, and the reason is actually pretty heartwarming.

Right up front: Take comfort in knowing your dog isn’t doing this to upset you. In fact, they love you so much that this is simply an attempt to feel closer to you. “First, your body has warmed the spot, so your dog gets a cozy temperature-controlled bed instantly,” celebrity dog trainer Chrissy Joy shares with Scary Mommy. “Second, your scent is concentrated there, and familiar human scent can be comforting and reassuring to dogs.”

Tracy Murray, dog expert and founder of Saving Fido Dog Walking, echoes this sentiment, explaining that it’s all coming from a place of love. "Warmth is a big part of it,” she admits. “In general, dogs are drawn to heat, and the spot you just left is prime. But it's not just about the warmth, because otherwise they'd be equally drawn to a patch of sun on the floor." Murray adds, "A dog uses their nose like we use our eyes, so the fact that the spot smells like someone they love is awesome. Taking over your place is like sleeping on a pile of your clothes."

And for those of you who worry your furry friend is doing this to establish themselves as the alpha over you, fear not. "The dominance idea has been pretty much debunked,” Murray continues. “With my background in psychology and years working with dogs, what I see is a dog who wants to be close to her person, not one trying to overtake or outrank them."

Just when you thought that little furball couldn’t get any sweeter!

On the other hand, it’s also possible that you yourself have accidentally encouraged this behavior without realizing it. “Another possibility is that stealing your spot has become a learned behavior,” licensed veterinarian Dr. Sarah-Jane Molier explains. “If you react gleefully or offer your dog attention when they jump in your spot, this is a form of ‘positive reinforcement.’ In other words, your dog has learned that stealing your spot gains them positive attention.”

Basically, the main takeaway here is that your dog is just as obsessed with you and you are with them! They want to be wherever you are (or were), and you can’t help but snuggle them for their thievery. So the next time you get up from your comfortable spot on the couch and come back to find it’s been taken over by a hairy, slobbery, wet-nosed seat-stealer, just remember that it’s their way of showing how much they love you.

And, you know what? I guess I can live with that. Luna has already stolen a big piece of my heart. I suppose she might as well have my spot on the couch too.

#419. My Favorite Airbnb: A Restored 200-Year-Old Trullo in Puglia With Room for My Whole Family

📅 Oct 26, 2026  |  Category: Business  |  Read Source →

As anyone who has ever planned a family vacation knows, booking a home that satisfies all of your party’s needs is a true art. By the time my parents, brother, and I embarked upon six days in Puglia in September, I had spent hours searching for a home that checked all the boxes. The nonnegotiables: My dad was set on staying in a trullo (the historic, conical stone homes native to the Itria Valley), my mother wanted laundry, and we all wanted a pool. And for me, a former design editor, aesthetics were always critical.

These criteria triangulated to find us at Trullo Giulio, 15 minutes outside of Martina Franca. Our host coordinated with her neighbor, Anna, to meet us at the property after the 90-minute drive from Bari. We could hear Anna’s tiny red farm truck puttering down the road to greet us, which should give you an image of just how rural this part of the region is—nothing but olive trees as far as the eye can see. Between my father’s three years of Italian lessons and some universal sign language, we got the lay of the land, which consisted of the main trullo (two beds, one bath) and two outbuildings that hosted two additional bedrooms, a bathroom, and the kitchen.

The decor was almost Santorinian in its whitewashed and blue-accented simplicity. The owners had taken great care to decorate the trullo with local textiles and pottery (I highly recommend a day trip to Grottaglie, the ceramic destination of the region) and features that allowed the original stone walls and vaulted ceilings to breathe. It’s modernized, but still retains its charm. And yes, there were a few quirks. The bedrooms in the main trullo were curtained off from the living room—don’t worry, the bathroom had a door—and the advertised AC units were only in the outbuildings. The Wi-Fi and cell service were pretty much nonexistent, which all but highlighted the fact that the true heart of the home was really the outdoor space.

The first thing we did after our tour with Anna was take in the pool. As the sun was setting, we dunked our tired feet in the water while sipping the local rosé and snacks Anna had left for us. Saltwater, with a whirlpool and an infinity edge that lets you gaze straight into the olive groves—it’s the showstopper of the property hands down. There’s also an outdoor shower for a quick rinse and multiple lounging spaces both in and out of the sun. We spent the majority of our time—when we weren’t on the pool deck—at the massive dining table under a shaded pergola.

A quick bite to eat featuring pizza and cheese

While we easily could have spent all of our days lounging poolside, the location of the trullo also made it a convenient launchpad for exploring the region. Aside from the much-slept-on town of Martina Franca, it's within an hour's drive of Alberobello, Ostuni, Polignano a Mare, and the many smaller beach towns along the coast—don’t miss the restaurant Ricciolandia if you’re a fan of urchin. Within a five-minute drive of the house is a delightfully well-stocked mini market and local fave Sale e Pepe, where we had more than one night of phenomenal pizza and grilled meats.

My favorite meal in Puglia, however, was one of (mostly) our own making. The final nonnegotiable we’d all agreed upon was that we had to take a pasta-making class before leaving Italy, which we also found on Airbnb. We joined Cristiana and her mother at their beachside trullo in Cozze for a sunny afternoon spent in the outdoor kitchen, where the humbling experience of making orecchiette by hand was enhanced by homemade limoncello and sparkling conversation.

No number of ancient churches, fun beach spots, or magical little towns could outweigh the best part of a family trip: The moments spent around the table. Trullo Giulio was the home base we needed to make those moments happen.

#3380. 8 Treadmill Workouts Pro Runners Swear By for Better Performance

📅 Oct 26, 2026  |  Category: Entertainment  |  Read Source →

Steal their secrets to making the most of your indoor runs.

It’s tough to escape the treadmill when the weather starts to turn. And while cruising through an easy run with entertainment is one thing, locking into intense speed intervals while staring at the same console is another. Without fresh scenery or a crew of training partners to pull you along, speedwork on the belt can test your focus before it tests your fitness.

Even professional runners know the feeling. When weather or logistics reroute a key workout indoors, they adapt and find ways to make the session productive, fast, and even fun.

Here, eight pros share the treadmill workouts they rely on to turn indoor interval sessions into serious gains.

Pro runner: Joe Klecker, 2020 Olympian in the 10,000 meters, who made his marathon debut at the 2025 New York City Marathon and went on to earn a PR at the 2026 Boston Marathon, finishing in 2:05:56 for 13th place.

Joe Klecker got this workout from his mother, Janis Klecker, a fellow Olympian who competed in the marathon in the 1992 Barcelona Games.

“My mom used to do this workout when she was training for the marathon in Minnesota,” Klecker tells Runner’s World. “The nice thing was, if I finished, say six miles, then the next time I did it, I’d move the pace faster, but if I was only able to get maybe five miles in, then I would know the next time I need to keep the pace there until I was in good enough shape to do the full six miles.”

As for how to lock into the right effort: “I keep this one at marathon pace or somewhere between marathon and half-marathon pace because the incline makes it quite a bit harder,” Klecker says. “But this workout is fun because you could compare it over time throughout the winter to where you were, say, from December to February.”

Pro runner: Amanda Vestri, who recently finished 15th among pro women at the 2026 Boston Marathon, recording a 2:24:49.

Amanda Vestri’s build for her 26.2 debut at the 2025 New York City Marathon, where she ran a 2:25:40, included a decent amount of treadmill training with workouts created by her former coach, Pete Rea of the now-defunct ZAP Endurance Group, which was based in Blowing Rock, North Carolina. The course is notoriously challenging and hilly, which was hard to closely simulate outside in North Carolina.

“If you live near flatter terrain, or you don’t have those rolling hills, treadmill workouts can be hugely beneficial for a race like New York,” Vestri tells Runner’s World. “I think it definitely prepared me for it.”

For her favorite workout, Vestri alternates inclines and declines, while pushing the pace. “With this workout, you’re starting with a longer interval, and then in between, you’re not jogging but rather floating and running at a steady rhythm about 40 to 50 seconds slower, and you end up getting a good amount of mileage in,” Vestri says.

Pro runner: Maggie Montoya, a professional marathoner with a personal best of 2:27:04, who trains with the Roots Running Project in Boulder.

Maggie Montoya used to loathe treadmill running, resorting to it only on the worst winter days when she was in college, when icy conditions or poor air quality would make training outside unsafe. She has since learned to embrace it now that she has a home treadmill and encounters those conditions more frequently.

“When the treadmill feels a bit monotonous on an easy run, I will fluctuate the incline and speeds every few minutes to add a little more stimulus and give a task that goes by at shorter increments than a full run doing the same thing,” Montoya tells Runner’s World. “Workouts aren’t as bad because there are usually built-in fluctuations throughout it.”

While Montoya typically does three miles for both her warmup and cooldown outdoors, she’ll usually do four and two miles, respectively, on the treadmill.

“I’ve been able to still nail all my workouts on a treadmill in recent years and am able to lock into a more consistent pace rather than when I might get out too fast in a rep outside,” Montoya says. “It has allowed a more controlled progression of a workout too, when required, which I feel is valuable.”

Pro runner: Emily Infeld, a 2025 U.S. Champion, 2016 Olympian, and 2015 World Championships bronze medalist, all in the 10,000 meters.

Emily Infeld has trained in Portland, Oregon for much of the last decade, which has made her no stranger to hopping on the treadmill to escape cold and rainy conditions.

“I have done quite a bit of work on the treadmill, I especially enjoy it for my double-threshold days for my morning session,” Infeld tells Runner’s World. “I’m not one for trying to make conditions ideal all the time, but sometimes it’s not feasible to go outside with snow and ice. It was pouring when I last did this, so it was nice to not have to deal with that on the road or track.”

“I like this workout because I can listen to music and turn my brain off, and I can get it done quickly in the morning to optimize rest for my second session,” Infeld adds.

Pro runner: Reed Fischer, who holds personal bests of 2:09:47 and 1:00:54 in the marathon and half marathon, respectively, and represented the U.S. in the marathon at the 2025 World Championships

Reed Fischer, who grew up in Minnesota and now trains with Tin Man Elite in Boulder, is very familiar with treadmill training.

“After 15+ years of treadmill workouts, I’ve got my ‘ideal’ treadmill workout pretty dialed in,” Fischer tells Runner’s World. “Threshold work [or half marathon pace for Fischer] is the best (in my opinion) bang for your buck on the treadmill. Anything faster can feel a little chaotic, and the reps are usually shorter, which means more fiddling with the belt speed to speed up and slow down. Anything slower means the reps get long and the workout gets pretty mundane.”

“For most people, threshold mile reps will probably fall somewhere between five to 10 minutes, which is a nice sweet spot for mental duration,” he adds.

Pro runner: Frank Lara, who holds personal bests of 2:09:53 and 1:01:00 in the marathon and half marathon, respectively.

Like Montoya, Frank Lara also trains with the Roots Running Project in Boulder and is also well-acquainted with moving runs indoors for adverse weather conditions or poor air quality.

“I’ve had the privilege of not having to use them too much early in my running career, but have acquired a great appreciation for them living in Colorado,” Lara tells Runner’s World. “On a treadmill, I don’t have to worry about planning a route, and time goes by fairly quickly if I’m watching the Big Bang Theory, or one of the Mission Impossible films.”

Lara says he doesn’t dwell too much on the distance he covers or the actual paces, as treadmills may not be calibrated properly. “It can take a few seconds for the treadmill to get up to speed, so I’ll often start adjusting the speed a few seconds before the start of the next rep,” he adds.

Pro runner: Michael Wardian, ultramarathoner and three-time 50K U.S. Champion, who broke the record for a series of back-to-back 50K races on all seven continents with a total time of 26:40:16

If you’ve gone beyond the marathon distance to train for an ultramarathon or mountain race, you know training isn’t only about mileage; you’ve got to consider the terrain and vertical climbing as well. Fortunately, simulating it can be much easier to do on the treadmill versus driving hours away from your home city every weekend in an effort to prepare.

“Uphill running forces your heart and lungs to work harder than flat running at a lower impact, making it one of the best aerobic workouts you can do,” Mike Wardian tells Runner’s World. “You’ll also hit the glutes, hamstrings, calves, and hip flexors much more than on flat terrain—the same muscles you need for mountain races, technical trail climbs, ultramarathons and fast hill surges.”

“A long treadmill climb teaches you to stay relaxed and controlled under sustained stress—perfect for ultras and long climbs,” Wardian adds. “For extra credit, I’ll add a 20-pound weight vest and slow the pace to 13:00 to 15:00.”

Pro runner: Zach Bitter, TrainingPeaks coach, ultramarathoner, and previous 100-mile world record holder, with a time of 11:19:13.

Zach Bitter prefers the treadmill to track his progress as he builds toward 100-mile races.

“I like it for the control it offers with respect to assessing training progress in an environment that is about as controlled as you can find, making comparing prior sessions to the current one easy,” Bitter tells Runner's World. “I prefer interval sessions on treadmills because they offer frequent changes, which breaks up the monotony of being in one spot and indoors.”

To track his progress over time, Bitter monitors his pace changes, while maintaining the same heart rate and perceived effort.

He also sometimes puts the incline between 6 and 10 percent to help build strength. Running uphill shortens your stride, shifts the foot strike toward the forefoot or midfoot, and reduces the vertical velocity of your body at landing, Bitter says.

“The goal for a session like this is targeting lactate threshold intensity, so it will fill a spot in my training when focusing on improving my pace at threshold,” Bitter says. “For my 100-mile race targets, it is a great way to raise the ceiling on my fitness, so work at lower intensities can be done at a higher quality when I start peaking for race day.”

A pioneering NASA space telescope is no more. In sad news for Swifties everywhere, the Neil Gehrels Swift Observatory has officially ended its mission after more than 20 years of tracking the most powerful explosions in the universe since the Big Bang.

According to a NASA announcement, the Swift team shut down the telescope's science operations Tuesday (Oct. 20) after the observatory fell too low in its orbit to continue taking reliable measurements of the cosmos. Welcome to the most impatient time of year—for skiers, at least. The dog days of summer are behind us and we’re eagerly awaiting the first lifts to start spinning. You don’t have to sit around twiddling your thumbs, though. Instead, put them to good use getting your gear prepped for the coming season

Ski shops have transitioned from summer to winter and are firing up their tuning machines and readying their bootfitting benches—without the long wait times of the regular season. So whether you need to update or maintain your gear, follow these six tips so all that’s left to do on opening day is load your gear into the car and drive.

Nothing ruins your first ski day like searching in vain for that one glove you swore was in your boot bag. And about those boots, didn’t you leave them in the downstairs closet back in April? The first item on your agenda is to make a shred list, literally. Work down from head to toe: Helmet, goggles, buff, jacket, gloves, pants, boots, skis, poles. Knowing where you left everything is half the battle. Taking a good look at their condition is critical.

“First thing’s first, if you need to stop by your local ski shop, go now before the season starts, and definitely before the holidays,” said Otto Gibbons, hardgoods supervisor for Sturtevants Ski Shope in Bellevue, Wash. Gibbons recommends taking a good look at your skis’ bases. “If there are any noticeable points of damage, like core shots or large gouges, get those skis tuned.” Look closely to see if there are different colors of base material in the core shot because if so, water can deteriorate your ski. “Large gouges will also slow you down on the hill and even affect how your ski hooks up at a lower edge angle,” Gibbons cautioned.

Next up, check your edges and sidewalls. “If you look along your skis’ sidewall and see any area where the edge is blown out, go to your local shop because sometimes those can be repaired and save the ski from a larger fail-point of separation,” Gibbons said. If you see rust, it’s the result of not drying your edges the last time you skied. A ski tech will tune both your side and base edges to remove the rust.

“If you cannot remember the last time you took your skis into the shop, do it now,” Gibbons said. “Skis should be waxed to keep the bases hydrated and fast.” If you are someone who holds on to gear forever, know that skis typically have a life expectancy of 300-400 days of hard skiing, so if your skis no longer have snap and response, it’s likely time to get a new pair.

When inspecting your boots, first make sure they are not missing any parts like buckles. Second, check the condition of the boot soles, because if you walked around the base area from morning through après last season, your soles may be ground down and therefore your binding may not release or retain your boot properly. “If you have replaceable soles, it is important to replace them if they have worn down close to the lug of the actual shell,” said Gibbons. A ski shop tech will help you figure out what replacement soles you need.

Now for the Cinderella approach: Put your boot on and make sure it still fits. It should feel like a firm handshake. “If your foot is different than it was before due to weight change, age, pregnancy or someone dropped a piano on it, then that might mean your boot fits differently,” cautioned Gibbons. “Remember you likely haven’t had your foot in constrictive footwear for a couple of months, so don’t panic; ‘a little tighter than I remember’ is common.” And make sure your liners are clear of foreign objects: “You’d be surprised what we find, including critters,” Gibbons told SKI.

The last thing to check is the condition of your liner. Stock liners have a life span of around 60 to 120 days of hard skiing before they get that packed-out feeling. “You can put a new aftermarket liner into a shell and breathe new life into the boot if you love your skiing experience in it,” said Gibbons. “If you are outperforming the boot, or the boot is old enough to vote, start looking for a new boot.”

If you took advantage of Labor Day sales and got new skis or boots, you still need to dial them in. Go now to mount your bindings on your new skis before the wait time increases at your local shop. Also, consider the compatibility of your setup if you made any changes. “If you got new Gripwalk soles on your boots, make sure your skis, including your powder boards, have bindings that are Gripwalk compatible, otherwise the binding will not function properly with the wrong soles in it,” Gibbons said.

If you have a new pair of boots, walk around the house in them to check for hot spots. “You’ll most likely have to get them punched or worked on,” said Ian Lochhead, head alpine ski coach for the University of Colorado. Lockhead recommends that recreational skiers prioritize comfort and an appropriate flex. “Ski racers often have boots that are too tight in the toe box, but you need that part of your foot to be able to move so you can be more athletic and control your edges better. If you’re into carving, get your canting and fit issues checked out by a boot fitter before you ski in new boots.”

Skis can perform great “out of the box,” but if you get a new pair, you might need to make some slight adjustments like de-tuning the sharp tips and tails. “Skis usually come good from the factory, but we always check them,” said Lochhead. “Any shop will be able to check the base and edge bevels of your new skis, and they can even tailor them to perform best for the drier snow in the Rockies or harder snow on the East Coast.”

Outerwear takes a hit every season—from rubbing up against your dirty car when loading your skis, to tears from your favorite glades. It would be a huge bummer if you find out there’s a large hole in the back of your pants on opening day, or that your jacket doesn’t repel water like it used to.

“It’s a good idea to wash your jacket in tech wash regularly, particularly with PFAS-Free DWRs,” said Will Dobrowski, materials coordinator for Stio. “These chemistries are affected more easily by oils and stains, so when the water on the outside of your jacket stops beading up, it’s time for a wash and dry. The dryer is actually what re-invigorates your DWR to help water bead more effectively, so if you need a quick fix in the morning, throw it in the dryer for 10 minutes on low heat.”

Dobrowski recommends checking for holes on the exterior of your outerwear, followed by interior seams to make sure the seam tape isn’t peeling away, which would allow water into the jacket. You can repair small holes with adhesive gear tape, but apply it to both sides. “I throw it in the dryer for 15 minutes after patching to help the glue adhere to the fabric,” he said. Lastly, check zippers, which are common places of wear. Some brands have programs to fix issues like replacing zippers, but keep in mind turnaround times vary.

Think back to last season: Did you hit your head? “As a rule of thumb, any fall that ‘rings your bell,’ even if you don’t get a concussion, would warrant getting a new helmet,” said Jon Jay, Sweet Protection’s North American brand manager. “It’s sort of like replacing a child’s car seat involved in any sort of car crash. Do you really want to risk a more serious injury because of unseen damage?”

Barring any crashes, it’s important to check the exterior shell for any warping or cracks because the outer shell of your helmet is your first line of defense, said Jay. Also make sure that the buckle is fully functional and the straps are not worn or frayed. You can remove the inner cloth liner and wash it, but don’t remove the Mips insert if your helmet has one.

“If you’re a skier who hasn’t taken a fall in a while, we recommend replacing your helmet every four to five seasons of regular use,” Jay told SKI. “Most modern helmets are built using very technically-engineered plastics, but they will lose strength and rigidity with regular use.”

Inspect the foam and strap to make sure there’s a good seal against your face and then check out the lens. “If your goggle lens has scratches, cracks, or cloudiness that interferes with your vision, it’s time to replace it,” said Grady Skelton, global snow marketing manager for Smith. “If you have interchangeable lenses, a damaged lens can be a quick, easy, and budget-friendly fix.”

Once you’ve checked these boxes, there’s only one thing to do: Refresh the forecast infinite times until you finally get the news you’ve been looking for.

I can relate, as I’m prone to staying up late to make the next day “easier,” which only deepens my exhaustion. "The illusion of being in charge of these complex and unrelenting demands provides a sense of agency," Krushefski explains.

My only question is: Sleeping in? What’s that?

My kids are getting older, but I still wake consistently throughout the night. Similarly, I find that when I’m super busy, I just can’t shut off my brain when I get to bed, even if I’m exhausted. Krushefski explains that the mental load of managing a household can cause rumination, repetitive thoughts that are hard to interrupt. Our brains keep scanning for the next thing we've forgotten or need to accomplish.

One basic way to make more time for sleep is to be honest about which responsibilities are really urgent, and which can wait, Bernal says. When we do too much for our families and don't let them practice independence, it’s to our detriment and theirs. I've recently worked harder to get my kids to do their own laundry, help pack their lunches, and clean up after dinner. These are essential life skills they need for adulting anyway, and they shouldn't all fall on me!

Harris suggests spending 10 minutes earlier in the evening writing down what's on your mind, along with a next step for each item, to help take the pressure off bedtime. Because the harder we try, the more it will evade us.

“No amount of sleep strategies can compensate for an absence of sleep opportunity,” warns Dzierzewski. In other words, we can try all the bedtime routines in the world, but if we don't have enough time to sleep, what's the point? For families with a partner or other support, Dzierzewski strongly recommends sharing nighttime responsibilities so each caregiver gets an uninterrupted stretch of sleep.

For persistent insomnia, it may be time to see a doctor to protect your health.

As Bernal beautifully puts it, “Sleep shouldn't be the reward you receive once you have done enough. Sleep is part of what allows you to live, love, think, work, and care for others in the first place.”

From Robert Rauschenberg and Josef Albers to Vija Celmins and Julie Mehretu, artists have tinkered outside their comfort zones at Gemini G.E.L.

LOS ANGELES — Founded in 1966 by Sidney B. Felsen and Stanley Grinstein, Gemini G.E.L. has long been one of the crown jewels for printmaking. To celebrate its 60th anniversary, Gemini invited curators Susan Dackerman and Helen Molesworth to mine the archive for the exhibition (Almost) Every Year: Sixty Years of Printmaking at Gemini G.E.L. Although the exhibition covers almost every year, the curators were primarily interested in how, as a workshop, the venue served as a place for dialogue among visiting artists and for tinkering outside normal routines or comfort zones.

As the chronology reveals, Gemini opened with a bang, bringing in celebrated New York artists such as Josef Albers, Man Ray, Robert Rauschenberg, Jasper Johns, Claes Oldenburg, Frank Stella, and Ellsworth Kelly. At the same time, they recognized the achievements of Los Angeles’s own growing artist community by inviting David Hockney, Ed Ruscha, Ron Davis, and Bruce Nauman. By the 1980s, women worked at Gemini, starting with Dorothea Rockburne and Vija Celmins, followed soon after by Susan Rothenberg and Elizabeth Murray. Today, as the curators noted in the gallery talk, Gemini’s artist list is distinguished by its gender equality.

Bruce Nauman, “Pay Attention” (1973), 1-color lithograph (photo David S. Rubin/Hyperallergic) (left); Edward and Nancy Kienholz, “The Econo-Can” (1977), metal with frensel lens system (photo courtesy Gemini G.E.L.) (right)

Several works stand out because the artists cleverly defy our expectations. Titled after a traditional Southern gospel hymn that was once recorded by Johnny Cash, “Great Speckled Bird” (2013) takes a nostalgic look at classic Americana. InfoQ Homepage News OpenTofu 1.13 Lets Module Authors Reduce Unknown Values at Plan Time

Oct 26, 2026 2 min read

OpenTofu released version 1.13 with functions that help module authors resolve more expressions during planning. Type and value hints can unblock plans when count or the keys used by for_each would otherwise remain unknown. The planner can determine how many resource instances to create without knowing all their eventual attributes, which can remain unknown until apply.

Martin Atkins, an OpenTofu maintainer, proposed the design in an RFC and merged the implementation in August. In an earlier issue, the reporter, csar398, wanted to retain YAML input but could not plan when the decoded value controlled count. yamldecode can return different types, including a null value, so an unknown input gives the planner neither a known type nor a non-null guarantee. Explaining the limitation, Atkins wrote: "... this is just too complex a situation for OpenTofu to infer automatically itself."

The convert function converts values to a specified type, giving a yamldecode result a known object type even when the YAML input is unknown. For conditional resources, combining that conversion with assumenotnull lets a count expression based on nullness resolve to zero or one while the object's contents remain unknown. The author must ensure that the generated YAML always represents an object of the specified type and never a null value. If a value unknown during planning later violates that guarantee, OpenTofu reports an error during apply.

Terraform shipped its equivalent convert function first, in version 1.15. Atkins later wrote in an OpenTofu issue that "Terraform has an equivalent feature with syntax exactly like what I proposed here", and the project decided to match its design.

Experimental linting runs four built-in warning rules, including core:unused-variable and core:count-instead-enabled. The -lint=all flag enables them with tofu validate, tofu plan or tofu apply. In their linting proposal, the maintainers describe the feature as their most-voted request; future work covers custom rules and broader policy checks. TFLint already offers plugin-based static analysis, including cloud-provider checks.

The opt-in Symbol Libraries experiment shares functions and type definitions through *.sym.hcl files. Libraries cannot directly access resources, data sources or provider functions, although callers can pass resource values into library functions. The team hopes to stabilise the feature in version 1.14.

Version 1.13 removes Windows Remote Management (WinRM) support from the remote-exec and file provisioners, changes base64gzip output bytes, requires macOS 13 Ventura or later, and is the last series with official 32-bit builds. It also adds Windows on ARM64 packages. Existing WinRM configurations need migration, and the Go library change behind base64gzip can trigger resource updates despite equivalent decompressed output.

OpenTofu shortened its development cycle to align with Go releases and supports the 1.13.x series until 1 August 2027. The project released version 1.13.2 on 21 October. Its two security changes address excessive CPU use during tofu init when connecting to an attacker-controlled HTTP/2 server and filter compromised intermediate certificates. The patch also fixes applying saved plans that use symbol libraries.
